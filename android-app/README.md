# تطبيق جمع البيانات - Android

## 📱 تطبيق متكامل لجمع البيانات مع الموافقة الصريحة

### ✨ الميزات

✅ جمع البريد وكلمة المرور بموافقة صريحة  
✅ رفع الملفات (صور، PDF، نصوص)  
✅ تشفير كلمات المرور SHA-256 على الجهاز  
✅ لوحة تحكم للمدير  
✅ عرض السجلات المحفوظة  
✅ حفظ البيانات محلياً على الجهاز  

---

## 🚀 التثبيت والتشغيل

### المتطلبات:
- Node.js 16+
- npm أو yarn
- Android Studio (اختياري للبناء)

### خطوات التثبيت:

```bash
# 1. الدخول للمشروع
cd android-app

# 2. تثبيت المكتبات
npm install

# 3. تشغيل التطبيق
npm start

# 4. في النافذة الجديدة، اختر:
# a - لـ Android Emulator
# i - لـ iOS Simulator
# w - للويب
```

---

## 📦 بناء APK للاندرويد

### الطريقة 1: بناء محلي (أسهل)
```bash
npm run android
# سيُفتح التطبيق على محاكي الاندرويد
```

### الطريقة 2: بناء APK للتوزيع
```bash
npm run build-android
# سينتج ملف APK قابل للتثبيت على أي جهاز اندرويد
```

## 🎯 كيفية الاستخدام

### الشاشة الرئيسية (Home)
1. أدخل البريد الإلكتروني
2. أدخل كلمة المرور
3. (اختياري) اختر ملفات للرفع
4. ضع علامة على "أوافق على نقل بياناتي"
5. اضغط "إرسال البيانات"

### لوحة التحكم (Admin)
1. أدخل اسم المستخدم وكلمة المرور
2. اضغط "تسجيل الدخول"
3. اضغط "تحميل السجلات" لرؤية البيانات

## ⚙️ الإعدادات

غيّر عنوان السيرفر في التطبيق إلى:
```
http://YOUR_SERVER_IP:3000/receive
```

مثال:
- محلي: `http://192.168.1.100:3000/receive`
- سحابي: `https://yourdomain.com/api/receive`

## 📱 المتطلبات (Package Dependencies)

- **react** - إطار عمل UI
- **react-native** - منصة Android/iOS
- **expo** - أدوات البناء والتشغيل
- **react-native-paper** - مكونات الواجهة
- **axios** - طلبات HTTP
- **react-native-async-storage** - تخزين محلي
- **expo-document-picker** - اختيار الملفات
- **expo-crypto** - التشفير
